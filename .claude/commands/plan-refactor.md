---

Please use the refactor-planner agent to analyze the current code and create a refactoring plan.

**Analysis Required:**
1. Identify refactoring opportunities (DRY violations, complexity, coupling)
2. Assess dependencies and risks
3. Create phased implementation plan
4. Sequence changes for minimal disruption
5. Estimate effort and timeline

**Output Format:**
- Current state assessment
- Refactoring recommendations (prioritized)
- Phased implementation plan (Phase 1, 2, 3...)
- Risk mitigation strategies
- Estimated timeline

**Focus Areas:**
[Specify: Entire codebase | Specific module | Feature area]

**Healthcare Compliance:** Ensure refactoring maintains WCAG 2.2 AA compliance and patient safety language.

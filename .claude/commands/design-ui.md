Please use the frontend-design skill to design this interface.

**Interface Type:** [Dashboard | Patient Portal | Form | Landing Page | Component]

**Target Users:** [Healthcare professionals | Patients | Administrators | LGU staff]

**Design Requirements:**

**Typography:**
- ❌ NEVER: Inter, Roboto, Arial, Helvetica
- ✅ PREFER: Space Grotesk (headlines), IBM Plex Sans (body), JetBrains Mono (data/codes)

**Color Palette:**
- **MYCURE Clinical:** Clinical Blue (#0066CC), Trust Navy (#003366), Medical Green (#00A86B)
- **MYCURE Government:** Manila Blue (#003DA5), Official Gold (#FCD116)

**Animation:**
- Healthcare-optimized timing (30% faster: 100ms, 150ms, 200ms)
- CSS-first (not JavaScript heavy)
- Reduced motion support required

**Accessibility:**
- WCAG 2.2 Level AA minimum (AAA preferred for text contrast 7:1)
- Keyboard navigation fully functional
- Screen reader compatible
- Focus indicators 3px minimum

**Healthcare Context:**
- Patient safety language in error states
- Offline-first if rural deployment
- Mobile-responsive (Philippine users predominantly mobile)

**Deliverables:**
- Component mockup/description
- CSS implementation (if applicable)
- Accessibility validation checklist
